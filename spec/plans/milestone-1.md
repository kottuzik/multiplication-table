# תוכנית Milestone 1 – תשתית אפליקציה, מסך בית עובד ופריסה ראשונה

מקורות: `MILESTONES.md` (Milestone 1), `PRD.md` (F1, ניווט, טקסטים מאושרים, מקרי קצה של כפתור "חזרה"), `ARCHITECTURE.md` (Stack, Modules, ADR-1, ADR-2, סעיף 9), `DESIGN.md` (1.1, 1.4, 2.1–2.5) והתמונות `wireframes.png`, `mockups.png`, `style-guide.png`.

## 1. היקף

**בתוך ה-Milestone:**
- שלד פרויקט React + TypeScript + Vite בשורש ה-Repository הקיים.
- ניווט בין `home` / `practice` / `about` ב-React State, מסונכרן עם כפתור "חזרה" של הדפדפן (ADR-1).
- מסך בית מעוצב במלואו (שם כטקסט, כיתוב משנה, איור SVG מקומי, שני כפתורים).
- מסכי לימוד ואודות **בסיסיים**: שורת ניווט עליונה (כפתור שפה + **חזרה**) וכותרת בלבד.
- כפתור שפה (גלובוס + "English") בכל המסכים, ללא פעולה.
- מילון טקסטים מקומי (עברית בלבד בשלב זה), במבנה שמוכן להוספת אנגלית.
- גופן Rubik מקומי (400/700, כולל עברית).
- Vitest + React Testing Library עם בדיקות ניווט בסיסיות (נדרשות כי ה-Workflow מריץ בדיקות).
- GitHub Actions Workflow לבדיקות, Build ופרסום ל-GitHub Pages.

**מחוץ ל-Milestone (לא לממש):** לוגיקת תרגול, בורר טבלאות, טבלת 10×10, טקסט אודות מלא, החלפת שפה בפועל, אנגלית, `localStorage`, PWA/Manifest/Service Worker/אייקונים.

## 4. גישה ופרטי מימוש

### 4.1 ניווט (ADR-1)
- `App` מחזיק `screen: 'home' | 'practice' | 'about'`.
- מעבר מהבית למסך משני: `history.pushState({ screen }, '')` (בלי לשנות URL) + עדכון state.
- מאזין `popstate`: חזרה ל-`home` (או למסך שב-`event.state`, אם קיים).
- כפתור **חזרה** באפליקציה קורא ל-`history.back()`, כך שהכפתור והדפדפן מתנהגים זהה.
- רענון תמיד פותח בבית (אין קריאת state מהכתובת).
- ב-Milestone 1 ה-state נמצא ב-`App`; ב-Milestone 2 יתווסף שם גם מצב התרגול (ARCHITECTURE סעיף 4).

### 4.2 מילון טקסטים
- `strings.ts` מכיל אובייקט `he` עם המפתחות הנדרשים כעת, בדיוק לפי טבלת הטקסטים המאושרים ב-PRD:
  `appName` "כפל כיף", `back` "חזרה", `languageButton` "English", `homeSubtitle` "לומדים את לוח הכפל בכיף!", `practiceButton` "בואו נתרגל", `aboutButton` "אודות", `aboutTitle` "אודות כפל כיף".
- כותרת מסך הלימוד הבסיסי: אין לה טקסט מאושר ב-PRD. במסך הבסיסי תוצג רק שורת הניווט וכותרת זמנית `appName` (כפל כיף) — ללא המצאת טקסט חדש. התוכן האמיתי יגיע ב-Milestone 2.
- הטיפוס של המילון מוגדר כך שב-Milestone 3 יתווסף אובייקט `en` עם אותם מפתחות, וכל רכיב קורא טקסטים רק דרך המילון (אין מחרוזות ממשק קשיחות ב-JSX).

### 4.3 עיצוב
- **Tokens** (`tokens.css`): כל צבעי טבלת 2.1, `--radius-card: 16px`, `--shadow-card: 0 4px 12px rgba(74,91,143,0.1)`, גדלי טיפוגרפיה H1 40 / H2 28 / H3 20 / Body 16 / Caption 14.
- **גופן:** ייבוא `@fontsource/rubik/400.css` ו-`700.css` (כוללים subset עברי ולטיני; Vite מעתיק את קבצי ה-woff2 ל-`dist`). `font-family: 'Rubik', sans-serif`. אין קישור ל-Google Fonts.
- **רקע:** לבן, עם כתמים עדינים בצהוב `#FFF9D6` ובכחול `#F1F6FF` + 2–3 כוכבים קטנים, ב-CSS/SVG, `aria-hidden`, `pointer-events: none`, בלי לגרום לגלילה אופקית (`overflow-x: clip` ל-body/wrapper).
- **Layout:** Mobile-first, עמודה ממורכזת עם `max-width` (~480px) בדסקטופ, ריפוד צדדי, `CSS Logical Properties` (`margin-inline`, `padding-inline`, `inset-inline-start`).
- **שורה עליונה (TopBar):** כמו ב-Wireframes: ב-RTL כפתור **חזרה** בצד ימין (תחילת השורה) וכפתור השפה בצד שמאל (סוף השורה). כפתור שפה: מסגרת מעוגלת, אייקון גלובוס SVG בקו כחול כהה + "English", ללא ▾. בבית — רק כפתור שפה, באותו צד.
- **כפתור חזרה:** רקע לבן, מסגרת `Primary`, חץ מצביע **ימינה** (→) בעברית.
- **מסך הבית (לפי Wireframe + Mockup):** H1 "כפל כיף" ב-Rubik Bold 40px בצבע `Primary` על כתם צהוב רך; כיתוב משנה ב-Body; איור; ואז שני כפתורים ברוחב מלא, אנכיים: **בואו נתרגל** (רקע `Primary`, טקסט לבן) ו-**אודות** (רקע כחול בהיר, טקסט `Primary`). החץ בכפתורים מצביע **שמאלה** (←) ומוצב בקצה הסוף של הכפתור (שמאל ב-RTL), כמו ב-Mockup.
- **חצים לפי כיוון:** החץ ממומש כ-SVG/תו אחד, וההיפוך נעשה ב-CSS לפי `[dir]` (למשל `:dir(rtl)` / `[dir="rtl"] .arrow { transform: scaleX(-1) }`), כך שב-Milestone 3 ההיפוך יעבוד אוטומטית.
- **אזורי מגע:** כל כפתור לפחות 44px גובה; כפתורי הבית גדולים יותר (~56px).
- **Focus:** `:focus-visible` עם outline ברור.

### 4.4 איור הבית
- קובץ `src/assets/home-illustration.svg`, נוצר ידנית בקוד: לוח מעט מוטה עם מסגרת כחולה בהירה (`#6E8ED6`/`#F1F6FF`) ומשטח כחול כהה (`#4A5B8F`), עליו הטקסט `3 × 4 = ?` בלבן; שני כוכבים צהובים (`#FDE74C`, קו מתאר `#2D2D3A`/`Primary`) עם עיניים וחיוך; כתם צהוב רך מאחור וכמה קווים קצרים "ידניים". בסגנון ה-Style Guide.
- הטקסט בתוך ה-SVG יומר ל-`<path>` או ייכתב עם `font-family` של Rubik; כדי שלא יהיה תלוי בגופן, עדיף לצייר את הספרות כ-path פשוטים או להשתמש ב-`<text>` עם Rubik (נטען באפליקציה) — ההחלטה בזמן הבנייה לפי מה שנראה טוב יותר.
- מוצג כ-`<img src=... alt="">` (דקורטיבי, כי המשמעות כבר נמצאת בשם ובכיתוב) ברוחב מוגבל ובגובה שלא דוחף את הכפתורים מחוץ למסך בטלפון רגיל.

### 4.5 בדיקות (Vitest + RTL)
`App.test.tsx`:
1. מסך הבית מציג "כפל כיף", "לומדים את לוח הכפל בכיף!", כפתורי "בואו נתרגל" ו-"אודות" וכפתור "English".
2. לחיצה על "בואו נתרגל" מציגה את מסך הלימוד עם כפתור "חזרה"; לחיצה על "חזרה" מחזירה לבית.
3. אותו דבר עבור "אודות" (כותרת "אודות כפל כיף").
4. אירוע `popstate` (סימולציה של כפתור הדפדפן) במסך משני מחזיר לבית.
5. אין מחרוזות שאינן מהמילון (בדיקה פשוטה שהטקסטים בבית תואמים לערכי `strings.he`).

`vite.config.ts`: `test: { environment: 'jsdom', setupFiles: './src/test/setup.ts' }`. סקריפט `"test": "vitest run"`.

### 4.6 GitHub Actions – `.github/workflows/deploy.yml`
- טריגר: `push` ל-`main` + `workflow_dispatch`.
- `permissions: contents: read, pages: write, id-token: write`; `concurrency: group: pages`.
- Job `build`: `actions/checkout`, `actions/setup-node` (Node LTS, `cache: npm`), `npm ci`, `npm test`, `npm run build`, `actions/configure-pages`, `actions/upload-pages-artifact` עם `path: dist`.
- Job `deploy`: `needs: build`, `environment: github-pages`, `actions/deploy-pages`.
- גרסאות ה-Actions העדכניות ייבדקו בזמן הבנייה.
- `vite.config.ts`: `base: '/multiplication-table/'` (גם ב-dev זה עובד; הכתובת המקומית תהיה `http://localhost:5173/multiplication-table/`).

## 6. אימות מול Definition of Done

| תנאי | איך ייבדק |
|---|---|
| `npm run build` מצליח, אין שגיאות Runtime | הרצת build + `npm run preview`/dev ובדיקת Console בדפדפן |
| שלושת היעדים, כפתורים ו-**חזרה** | בדיקות Vitest + לחיצות בדפדפן |
| כפתור "חזרה" של הדפדפן מחזיר לבית ואינו יוצא | בדיקת `popstate` ב-Vitest + Back בדפדפן בפועל |
| התאמה ל-Wireframes (RTL), צבעים, פונט, סגנון | צילום מסך והשוואה ל-`wireframes.png` / `mockups.png` |
| איור SVG מקומי, שם כטקסט | בדיקת קבצים + צילום מסך |
| Rubik מקומי, ללא Google Fonts | רשימת בקשות רשת: כל קבצי ה-woff2 מ-localhost, אין פנייה לדומיין חיצוני |
| כיווני חצים (חזרה → ימינה, מעבר → שמאלה) | צילום מסך |
| שמיש בנייד, ללא גלילה אופקית | הקטנת חלון ל-320px ו-375px; בדיקה ש-`scrollWidth <= clientWidth` |
| Workflow קיים ותקין | קריאת הקובץ + הרצת אותן פקודות (`npm ci`, `npm test`, `npm run build`) מקומית. הפרסום בפועל ובדיקת הכתובת הציבורית — רק אחרי Push מאושר והפעלת Pages על ידי המשתמש (בהדרכה) |
